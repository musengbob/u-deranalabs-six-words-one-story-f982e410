Six words, one story: "The lighthouse blinked; nobody came home." A keeper tends the light night after night, signalling to a shore that never answers — the blink is a promise, and the empty house is the punchline. The whole arc of waiting, loss, and stubborn hope fits in a single breath, and the semicolon holds the turn between duty and grief.

## Run it

```sh
node main.ts
```

This validates the story (exactly six words, one line, no trailing newline) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
